# 权限与数据保护

本人 DWS OAuth 登录态 → 固定组织/账号 profile → 目标 baseId → 服务端权限校验。

`.env` 只定位库；提示词/Skill/tableId 不授予权限。脚本在列目录时记录身份，导出和恢复核对相同 corp_id/user_id，不跟随默认账号变化。

- 同事用自己账号，只在服务端授权范围内操作。
- 同一个 Windows 用户环境可能沿用已登录身份，操作前核对账号。
- 目录可见不等于全部记录可读、可创建视图或可导出。
- 界面隐藏和筛选不是权限隔离，不能据界面“只显示三张表”推断权限。
- 本项目没有多个真实权限账号，不宣称已做跨账号/逐行权限审计。离线测试只证明工具不会在身份不符时继续。

副作用仅是在已选表新建一个 Grid 视图并删除本次 viewId；原表与原视图不修改。只读协作者如果不能建视图，流程停止，不借用管理员账号或降级整库导出。

`.env`、`tmp/`、`output/`、`dist/` 不入 Git。清单和 state 含账号、表、任务、字段元信息，仅用于本地恢复。落地 Excel 不再受在线钉钉访问控制，应按公司文件管理要求存放。

发布 ZIP 只含显式允许的技能、文档、示例配置、安装器及脱敏测试报告，不含真实表名、账号、下载路径、工作簿哈希、业务规模或业务数据。下载签名 URL 不持久保存；凭据由官方 DWS 管理，本项目不复制登录态。

ZIP SHA256 用于比对可信来源，MANIFEST 用于检查包内容损坏或修改，**不是发布者数字签名**。同时被替换的文件和校验码不能证明来源，接收者应从可信维护者取得包和校验码。
