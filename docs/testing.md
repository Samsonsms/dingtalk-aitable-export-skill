# 测试与验收

```powershell
python -m unittest discover -s tests -v
python tools/check.py
```

离线测试使用合成 XLSX XML 和 FakeDws，不使用生产账号/数据。覆盖：

| 范围 | 验收 |
|---|---|
| 选表 | 列目录无写操作；过滤测试；空清单/重名拒绝；改名后重选 |
| 身份 | 不匹配停止；固定 profile |
| 范围 | 只为指定 tableId 建一视图、提交一个 scope=view 任务 |
| 完整性 | 缺字段、隐藏、筛选、排序时不导出 |
| 恢复 | TIMEOUT_ERROR 同任务续跑，完成后重复恢复幂等 |
| 未知写入 | 创建/提交响应丢失不重放、不按名称删除 |
| 清理 | 下载失败清理；清理失败不报成功；恢复不重复下载 |
| 文件 | 多 Sheet/错名/缺列/错序/额外列/缺样式失败 |
| 原样 | 缓存公式、引用、空表、源错误保留；哈希一致 |
| 本地 | 锁、拒绝覆盖、文件名、HTTPS、curl 参数数组 |
| 配置 | BOM/别名/注释；重复/冲突键拒绝；URL 不保存 |
| 发布 | 旧/失败证据阻止发布；白名单；包篡改阻止安装；拒绝覆盖旧技能 |

真实冒烟用已授权单表验证官方认证和真实返回结构、全字段/原生样式、公式及引用非空结果、下载字节未变、临时视图删除、已有视图配置前后一致、完成后重复恢复不重导。

测试结果由程序生成，ZIP 的 `TEST_REPORT.json` 记录该版本测试数量、DWS 版本、检查结果、源码摘要，不手工填写通过。

不声称已经覆盖所有账号权限组合、所有数据类型或业务公式正确性；没有逐行查询源记录对账。源码摘要绑定是版本对应性检查，不是防恶意维护者伪造的数字签名。

任何测试失败、版本变更未重测、真实证据缺失、单表/字段/样式校验失败、计算值覆盖缺失、清理未确认或原视图被改动，都禁止打包安装。
