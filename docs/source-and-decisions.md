# 参考依据与实现选择

参考用户提供的《钉钉AI表格原样导出-运行手册.md》（2026-09-10 读取），原文件未修改。

| 原要求 | 实现 |
|---|---|
| 官方 npm 安装与设备授权 | Skill/手册指导，由本人完成授权 |
| .env 的 DINGTALK_BASE_ID | 兼容 baseId，重复/冲突拒绝 |
| 列表排除测试，等用户选 | 独立 list 与 export 子命令 |
| 无名称 Grid 视图 | 原命令，增加全字段/无隐藏/筛选/排序核查 |
| scope=view，单表 excel | 固定参数，不拉记录重拼或下载整库 |
| 提交 1000，轮询 30000 | 沿用 taskId，轮询上限后保存状态 |
| curl.exe 下载 | HTTPS 原字节下载，不用 Invoke-WebRequest |
| 删除临时视图 | 真实 viewId 精确清理，删除前查存在性 |
| Sheet、字段、样式校验 | 标准库只读 ZIP/XML 和文件摘要 |

为分发增加自包含脚本、固定账号、恢复状态、离线/真实测试、发布门禁、安装器和维护文档。不嵌入个人 Base、账号或数据。

“原样”保留官方输出，不复刻页面、不修业务公式。临时视图仍需账号真实权限，隐藏不是权限屏障。

[官方 DWS 项目](https://github.com/DingTalk-Real-AI/dingtalk-workspace-cli)。以当前安装版本的精确命令 schema 和实际返回为准，升级后重测。
